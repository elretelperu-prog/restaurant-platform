# Restaurant QR Platform — React migration V1
Migración del prototipo La Terraza a React + Vite, conservando el diseño y StPageFlip. El pliegue SVG se hará en el siguiente paso después de comparar esta migración con el prototipo actual.

## Ejecutar
1. Instala Node.js compatible con Vite.
2. `npm install`
3. `npm run dev`
4. Abre la URL local que muestre Vite.

## Producción
`npm run build`
